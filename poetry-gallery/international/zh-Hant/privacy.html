每日詩詞 · 隱私權政策

2026-10-15 · 317

每日詩詞由 Lee 提供。本政策說明 App 的數據處理方式，以及你主動聯繫技術支持時的處理方式。

閱讀數據與廣告服務

每日詩詞無需註冊或登錄。收藏、閱讀歷史、詩歌內容和閱讀設置僅在設備中使用，不發送給開發者或廣告服務。App 使用 Google AdMob 展示插屏和詩集列表原生廣告，並使用 Google 用戶消息平臺（UMP）管理適用的隱私選擇。

廣告 SDK 可能處理 IP 地址（可推斷大致位置）、設備或應用標識符、廣告展示與互動、崩潰和性能診斷等信息，用於廣告投放、衡量和防欺詐。本版本請求非個性化廣告，關閉發佈商第一方 ID，不請求跨 App 跟蹤授權；非個性化廣告仍涉及上述數據處理。

廣告與隱私選擇

首次使用會話不展示廣告。之後，廣告可能在閱讀後返回詩集時或詩集列表中展示。無網絡、廣告未就緒或隱私條件不滿足時可繼續閱讀。在適用地區，廣告請求前會通過 UMP 獲取所需的隱私選擇；需要時可在「閱讀設置」的「廣告隱私選項」中修改選擇。廣告次數和閱讀時長的限頻記錄僅保存在當前設備。

僅在設備中保存的記錄

爲了記住你的閱讀習慣，App 在當前設備保存收藏、已讀記錄、閱讀位置和閱讀設置。這些信息不發送給開發者，當前版本也不提供賬號雲同步。你可以在 App 中調整相應設置或收藏；刪除 App 可能移除其本機數據。iOS 設備備份和恢復取決於你的系統設置及所使用的備份服務。

離線內容與朗讀

詩文、插畫和朗讀文件隨安裝包提供。朗讀爲發佈前預先製作的 AI 合成音頻。App 運行時不會調用 Azure 或其他在線語音合成服務，不會上傳你正在閱讀的內容，也不使用麥克風錄製聲音。

保存與分享詩箋

你主動選擇保存或分享詩箋時，App 在本機生成圖片，並通過 iOS 系統分享面板交由你選擇的目的地處理。保存圖片可能需要系統的相冊添加權限；App 不讀取照片庫。分享給第三方 App 或服務後，該接收方的數據處理適用其自己的隱私政策。

技術支持郵件

如果你主動發送郵件至支持郵箱，收件方和郵件服務商會處理你提供的郵箱地址、郵件正文及附件。開發者僅爲回覆、排查和處理你的請求使用這些信息，不將其用於廣告或出售給他人。請僅提供解決問題所必需的信息；你可通過同一郵箱請求刪除相關支持郵件，依法需要保留的情況除外。

權限與第三方服務

App 不請求位置、通訊錄、攝像頭或麥克風權限，也沒有推送通知服務。App Store 下載、支付賬戶管理（如有）和系統級診斷或備份服務由 Apple 提供，適用 Apple 的相關政策；這些不構成 App 自行集成的數據收集功能。

支持網站的託管

本支持網站由 GitHub Pages 託管，頁面不添加統計腳本、廣告、Cookie 或在線表單。訪問本網站時，GitHub 會出於安全目的記錄訪問者的 IP 地址，具體處理方式見 GitHub 隱私聲明。訪問支持網站與 App 內的離線閱讀是獨立的。

政策更新與聯繫

若後續版本的數據處理方式發生變化，我們會同步更新本頁及 App Store 隱私信息。有關本政策或數據處理的問題，請聯繫 071427li@163.com。
