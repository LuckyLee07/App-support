每日诗词 · 隐私政策

2026-10-15 · 317

每日诗词由 Lee 提供。本政策说明 App 的数据处理方式，以及你主动联系技术支持时的处理方式。

阅读数据与广告服务

每日诗词无需注册或登录。收藏、阅读历史、诗歌内容和阅读设置仅在设备中使用，不发送给开发者或广告服务。App 使用 Google AdMob 展示插屏和诗集列表原生广告，并使用 Google 用户消息平台（UMP）管理适用的隐私选择。

广告 SDK 可能处理 IP 地址（可推断大致位置）、设备或应用标识符、广告展示与互动、崩溃和性能诊断等信息，用于广告投放、衡量和防欺诈。本版本请求非个性化广告，关闭发布商第一方 ID，不请求跨 App 跟踪授权；非个性化广告仍涉及上述数据处理。

广告与隐私选择

首次使用会话不展示广告。之后，广告可能在阅读后返回诗集时或诗集列表中展示。无网络、广告未就绪或隐私条件不满足时可继续阅读。在适用地区，广告请求前会通过 UMP 获取所需的隐私选择；需要时可在「阅读设置」的「广告隐私选项」中修改选择。广告次数和阅读时长的限频记录仅保存在当前设备。

仅在设备中保存的记录

为了记住你的阅读习惯，App 在当前设备保存收藏、已读记录、阅读位置和阅读设置。这些信息不发送给开发者，当前版本也不提供账号云同步。你可以在 App 中调整相应设置或收藏；删除 App 可能移除其本机数据。iOS 设备备份和恢复取决于你的系统设置及所使用的备份服务。

离线内容与朗读

诗文、插画和朗读文件随安装包提供。朗读为发布前预先制作的 AI 合成音频。App 运行时不会调用 Azure 或其他在线语音合成服务，不会上传你正在阅读的内容，也不使用麦克风录制声音。

保存与分享诗笺

你主动选择保存或分享诗笺时，App 在本机生成图片，并通过 iOS 系统分享面板交由你选择的目的地处理。保存图片可能需要系统的相册添加权限；App 不读取照片库。分享给第三方 App 或服务后，该接收方的数据处理适用其自己的隐私政策。

技术支持邮件

如果你主动发送邮件至支持邮箱，收件方和邮件服务商会处理你提供的邮箱地址、邮件正文及附件。开发者仅为回复、排查和处理你的请求使用这些信息，不将其用于广告或出售给他人。请仅提供解决问题所必需的信息；你可通过同一邮箱请求删除相关支持邮件，依法需要保留的情况除外。

权限与第三方服务

App 不请求位置、通讯录、摄像头或麦克风权限，也没有推送通知服务。App Store 下载、支付账户管理（如有）和系统级诊断或备份服务由 Apple 提供，适用 Apple 的相关政策；这些不构成 App 自行集成的数据收集功能。

支持网站的托管

本支持网站由 GitHub Pages 托管，页面不添加统计脚本、广告、Cookie 或在线表单。访问本网站时，GitHub 会出于安全目的记录访问者的 IP 地址，具体处理方式见 GitHub 隐私声明。访问支持网站与 App 内的离线阅读是独立的。

政策更新与联系

若后续版本的数据处理方式发生变化，我们会同步更新本页及 App Store 隐私信息。有关本政策或数据处理的问题，请联系 071427li@163.com。
