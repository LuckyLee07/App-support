成语长河

隐私政策

更新日期：2026 年 10 月 25 日

成语长河由 Lee 提供。我们希望你安心地阅读与游历，不需要为此建立账户。

应用内的数据

学习进度、收藏、答题草稿、设置与提醒安排保存在你的设备上。应用不设置自有用户数据服务器，不主动上传这些记录，不将学习记录或笔记提交给广告服务，也不出售个人数据。

广告与隐私选择

应用接入 Google AdMob 和 UMP 隐私授权管理服务。广告启用时，相关服务可能处理 IP 地址（可推断大致位置）、设备标识、广告互动及诊断信息，用于广告展示与衡量、防作弊和服务运行。处理与保留规则见 Google 隐私政策。当前采用非个性化配置、关闭发布商第一方 ID，不请求跨应用跟踪授权；这不代表服务完全不处理数据。

激励广告由用户主动选择，获得广告奖励后揭晓本关答案。没有免费直接揭晓入口；不观看、未获得奖励或加载失败时，可继续自行猜题、使用免费分层提示和回看已完成故事。部分新关卡完成后，离开通关结果页时可能展示可关闭的插屏广告；设有通关数量与时间间隔限制，广告未准备好时直接继续，不在阅读或答题中插入。应用按 UMP 结果展示所需授权表单；需要隐私选择入口时，可在“我的 → 广告隐私设置”或“隐私说明”重新选择。应用面向普通受众，不专门面向儿童。广告是否展示取决于网络、隐私选择和广告可用性。

第三方服务

  • Google Mobile Ads SDK（AdMob）：用于激励与插屏广告，可能处理大致位置、设备或应用标识、广告互动及诊断信息。
  • Google User Messaging Platform（UMP）：用于更新广告隐私选择状态、展示适用消息并保存相关选择。
  • GitHub Pages：仅在访问网页时提供静态页面托管。

Google 和 GitHub 服务可能在你所在国家或地区以外处理相关数据，其处理、保存及跨境安排以各自隐私政策为准。我们不向这些服务提交你的成语答题记录、收藏或笔记。

图片与读音

简体与繁体中文故事、图片与普通话成语读音随应用提供。读音在内容制作阶段预先生成，应用内播放不连接第三方语音服务，不录制声音，也不申请麦克风权限。

权限

仅在你启用提醒时请求通知权限，可在系统设置中关闭。不请求通讯录、位置、相机或麦克风权限。

导出与删除

你可主动导出 JSON 备份，通过系统分享面板自行决定接收方。备份包括中文模式的学习、答题、文名、未完成课程、收藏、摘录笔记和阅读设置，简体与繁体共用这些记录。可从文件手动恢复，导入前会预览并选择合并规则；没有自动云同步。中文模式重置学习记录会保留收藏、摘录与笔记；重新完成对应关卡后可查看；卸载应用会移除应用本地数据，系统备份的管理由 iOS 设置决定。

主动联系支持

仅在你主动发送反馈时，我们会收到邮件地址、邮件正文及你附带的设备、版本、截图等资料，用于回复、排查问题和处理勘误。邮件由你使用的邮件服务和支持邮箱服务处理。请勿发送无关敏感资料；需要查询或请求删除反馈邮件时，可通过下方邮箱联系我们。我们按处理问题所需期限保留反馈，不设定与实际运营不符的固定删除承诺。

网页与外部服务

支持页与本政策由 GitHub Pages 托管。访问时，GitHub 可能处理 IP 地址、浏览器与请求日志，以提供网站并维护安全，详见 GitHub 隐私声明。本页面没有嵌入广告、统计脚本、表单或第三方字体。打开 Google、GitHub 等外部链接时，对应服务适用其自身政策。

未成年人

应用无需账户，也不会主动收集儿童身份信息。监护人可协助使用及反馈；若你认为反馈邮件包含不必要的未成年人信息，请联系我们处理。
